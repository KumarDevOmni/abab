HOW TO ADD ANOTHER GUEST
1. Put the guest's photo in the "photos" folder (a square or portrait JPG works best, e.g. first-last.jpg).
2. Open guests.js, copy the TEMPLATE block at the bottom, fill in the details, and make sure the photo name matches.
3. Save / commit. The new guest appears on index.html automatically.
   Link for that guest:  guest.html?id=first-last

To change the pandal name or the number of seconds per slide, edit the SITE block at the top of guests.js.
Controls: tap/click = next slide, arrow keys = back/next, F = fullscreen.
